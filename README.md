# ZIPANG 地元だより

三重県の報道発表、名古屋市・可児市のイベントRSSを読み、地元交流ワールド ZIPANG の掲示板用JSONを配信します。

[掲示データを開く](https://chihaya369.github.io/zipang-news/news.json)

収集は毎時7・22・37・52分に実行予定です。配信されるのは地域名、テーマ、編集した案内名、出典、発信日、公式記事へのリンクです。開催日を特定できるときは別項目に記録します。申込状況や正確な日時は各記事をご確認ください。

## 運用

配信元は `sources.json`、地域・テーマの分類と表示項目は `collect.py` で管理します。各配信元から過去45日以内の最大10件を掲載します。「各地方の今週の一件」には各地方から過去7日以内の新着を1件ずつ選びます。受信障害が一部のみの場合は直近48時間以内に取得したその配信元のデータを利用します。全件が取得不能の場合は公開中の版を維持します。集計の日時と部分障害はJSONに記録します。

Actionsの「ZIPANG local news」から手動更新できます。予定実行は混雑で遅れる場合があります。公開リポジトリに60日間活動がないとGitHubが予定実行を停止することがあるため、停止表示がある場合は同じ画面から再開してください。

ローカルでは Python 3.11 以上で `python collect.py` を実行すると、`public/news.json` を生成します。追加ライブラリは不要です。
